# Guía práctica de redes RA 4

Guía estática de subnetting, VLAN, switch y router para la ficha 3399813.

## Uso

Abre index.html o consulta la publicación en https://jabermudez.github.io/guia-practica-redes-ra4/.

Completa los registros dentro de cada actividad. Las preguntas ofrecen realimentación y los verificadores comparan los cálculos con los bloques mínimos consecutivos definidos para este ejercicio.

La bitácora incluye identificación, subredes, direccionamiento por PC, consultas de S1 y R1, seis trayectos de conectividad, diagnóstico y reflexiones. Los nombres de evidencia hacen referencia a archivos que el equipo conserva por separado.

## Guardado y entrega

El navegador conserva los registros mediante localStorage cuando está disponible. Los datos anteriores se muestran en la sección de apuntes de la versión previa. Descarga el informe Markdown para entregar y el respaldo JSON para continuar en otro navegador. La importación valida la estructura del archivo y solicita confirmación antes de reemplazar los datos.

El informe y el respaldo señalan los campos sin diligenciar. La revisión comprueba presencia de datos, consistencia de subredes, direccionamiento y conteos. Cada equipo debe contrastar sus registros con las configuraciones y evidencias reales.

## Publicación

GitHub Pages sirve index.html, styles.css y app.js desde main en la raíz. No se requiere compilación. Las fuentes web disponen de alternativa local. Copiar comandos utiliza el portapapeles del navegador o permite seleccionar el bloque manualmente.

El documento Word conservado en el repositorio corresponde a la edición anterior. La guía web incorpora los formularios estructurados y las funciones de esta actualización.
