# Guía práctica de redes para GitHub Pages

Contenido estático. Abre index.html para usar la guía localmente.

Para GitHub Pages, carga los archivos de esta carpeta en la raíz de un repositorio. En Settings > Pages selecciona Deploy from a branch, la rama que contiene los archivos y la carpeta /(root). Guarda la configuración y abre la URL que entregue GitHub.

La página incluye repaso de conceptos, verificador del ejercicio VLSM, preguntas con realimentación, comandos para copiar y bitácora descargable. La bitácora se guarda en el navegador cuando el almacenamiento local está disponible. La función de copiar puede requerir HTTPS o selección manual del bloque.

La guía funciona sin compilación. Las fuentes web tienen una alternativa local. Conserva index.html, styles.css, app.js y el documento Word juntos.
