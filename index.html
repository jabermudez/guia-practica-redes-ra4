Conceptos que vas a recuperar

IP

Internet Protocol. Dirección lógica que identifica una interfaz en una red. En esta práctica usas IPv4.

IPv4

Internet Protocol version 4. Dirección de 32 bits escrita en cuatro octetos, por ejemplo 172.16.50.2.

Subred y máscara

Una subred es una parte del bloque original. La máscara indica qué bits identifican la red y cuáles a sus hosts.

CIDR y prefijo

Classless Inter-Domain Routing. /25 indica 25 bits de red y deja 7 bits de host. Su máscara es 255.255.255.128.

VLSM

Variable Length Subnet Mask. Permite usar prefijos diferentes según la capacidad requerida por cada área.

Host y broadcast

Un host es un equipo o interfaz con dirección en la red. Broadcast es la última dirección de una subred, destinada a todos sus hosts.

Gateway

Puerta de enlace. Interfaz del router de la misma subred que el PC, utilizada para llegar a otras redes.

VLAN

Virtual Local Area Network. Separa un switch en redes lógicas. En esta práctica cada VLAN tiene su propia subred.

Puerto de acceso y troncal

Un puerto de acceso pertenece a una VLAN. Un enlace troncal transporta varias VLAN entre dispositivos.

IEEE 802.1Q y dot1Q

Etiquetado de tramas que identifica la VLAN en el enlace troncal. El número de VLAN debe coincidir en S1 y R1.

Switch y MAC

Un switch reenvía tramas dentro de una VLAN según su tabla MAC. MAC significa Media Access Control, dirección de una interfaz de enlace.

Router y subinterfaz

Un router reenvía paquetes entre redes. Una subinterfaz es una división lógica de una interfaz física asociada aquí a una VLAN.

ARP

Address Resolution Protocol. Averigua la dirección MAC del siguiente salto IPv4 en el enlace local.

ICMP y ping

Internet Control Message Protocol. Ping usa mensajes de eco para comprobar alcance IP y respuesta de retorno.

CLI y configuración

Command Line Interface. Consola de comandos. Running-config es la configuración en uso y startup-config la que se conserva para reiniciar.

Regresión

Prueba de una función que ya operaba para confirmar que sigue funcionando después del ajuste.

Calcula y verifica las subredes

Asigna bloques consecutivos desde el inicio del /24. Usa el menor bloque que soporte cada área y comienza por la de mayor tamaño.

  1. Encuentra h con 2h − 2 ≥ hosts requeridos. Los dos valores reservados son la red y el broadcast.
  2. Calcula el prefijo con 32 − h. Obtén la máscara decimal.
  3. El tamaño del bloque es 2h. En este ejercicio los saltos están en el último octeto.
  4. La red del siguiente bloque empieza inmediatamente después del broadcast anterior.
  5. Reserva el primer host como gateway y los dos siguientes para los PC del área.
Un ejemplo diferente para recordar el procedimiento

Para 12 hosts, 2⁴ − 2 = 14. Se usa /28, máscara 255.255.255.240 y bloques de 16 direcciones. En 192.168.5.0/28, los hosts van de .1 a .14 y el broadcast es .15. El siguiente bloque empieza en .16.

Configura S1 y verifica cada VLAN

En S1 abre CLI y pulsa Enter para acceder a la consola. enable abre el modo privilegiado y configure terminal permite cambiar la configuración. exit vuelve al nivel anterior y end regresa al modo privilegiado.

  1. Crea VLAN 10 y 20.
  2. Asigna los dos PC de cada área a puertos de acceso de su VLAN.
  3. Configura el enlace a R1 como troncal y permite VLAN 10 y 20.
  4. Consulta el resultado y guarda la configuración. Al ejecutar copy running-config startup-config, confirma el nombre propuesto con Enter.

Configura R1 y comprueba las rutas

Una sola conexión física a S1 transporta ambas VLAN. R1 utiliza una subinterfaz para cada VLAN. Su dirección IP será la puerta de enlace de los PC de esa subred.

  1. En la consola de R1 habilita la interfaz física Gi0/0.
  2. Crea Gi0/0.10 con etiqueta dot1Q 10 y Gi0/0.20 con etiqueta dot1Q 20.
  3. Reemplaza los campos IP y MASCARA por tus cálculos antes de ejecutar las líneas ip address.
  4. Comprueba direcciones, estados y rutas. Guarda la configuración.

Secuencia de referencia para R1

enable
configure terminal
hostname R1
interface gigabitEthernet 0/0
no shutdown
exit
interface gigabitEthernet 0/0.10
encapsulation dot1Q 10
ip address IP_GATEWAY_ADMIN MASCARA_ADMIN
exit
interface gigabitEthernet 0/0.20
encapsulation dot1Q 20
ip address IP_GATEWAY_OPER MASCARA_OPER
end
show ip interface brief
show ip route
copy running-config startup-config
Comprender las dos líneas de direccionamiento

Para Gi0/0.10 usa el primer host utilizable y la máscara /26 de Administración. Para Gi0/0.20 usa el primer host utilizable y la máscara /27 de Operaciones. El ID de VLAN de encapsulation dot1Q debe coincidir con el transportado por S1.

El switch real muestra Gi1/0/3 en lugar de Fa0/3. ¿Qué adaptas?

Relaciona el puerto físico con el diagrama. Ajusta el comando de interfaz y registra el nombre real; conserva la VLAN que corresponde al PC.

El enlace está activo y las IP son correctas, pero ping falla. ¿Qué comprobarías?

Verifica VLAN, gateway, ruta, retorno y políticas ICMP del destino. Un servicio puede comportarse diferente; registra qué prueba ejecutaste.

La red responde a ping. ¿Qué harías para comprobar que soporta a todos los usuarios?

Define requisitos de disponibilidad, rendimiento y calidad y prepara mediciones comparables. Esto continúa en el proyecto del RA 4.
