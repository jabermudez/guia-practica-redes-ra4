El reto

Reto. Una empresa necesita separar Administración y Operaciones y permitir la comunicación entre ambas áreas. Tu equipo calculará las subredes, montará la red y comprobará su funcionamiento. Guarda este montaje como punto de partida del proyecto final.

Conceptos que vas a recuperar

IP

Internet Protocol. Dirección lógica que identifica una interfaz en una red. En esta práctica usas IPv4.

IPv4

Internet Protocol version 4. Dirección de 32 bits escrita en cuatro octetos, por ejemplo 192.168.10.2.

Subred y máscara

Una subred es una parte del bloque original. La máscara indica qué bits identifican la red y cuáles a sus hosts.

CIDR y prefijo

Classless Inter-Domain Routing. /26 indica 26 bits de red y deja 6 bits de host. Su máscara es 255.255.255.192.

VLSM

Variable Length Subnet Mask. Permite usar prefijos diferentes según la capacidad requerida por cada área.

Host y broadcast

Un host es un equipo o interfaz con dirección en la red. Broadcast es la última dirección de una subred, destinada a todos sus hosts.

Gateway

Puerta de enlace. Interfaz del router de la misma subred que el PC, utilizada para llegar a otras redes.

VLAN

Virtual Local Area Network. Separa un switch en redes lógicas. En esta práctica cada VLAN tiene su propia subred.

Puerto de acceso y troncal

Un puerto de acceso pertenece a una VLAN. Un enlace troncal transporta varias VLAN entre dispositivos.

IEEE 802.1Q y dot1Q

Etiquetado de tramas que identifica la VLAN en el enlace troncal. El número de VLAN debe coincidir en S1 y R1.

Switch y MAC

Un switch reenvía tramas dentro de una VLAN según su tabla MAC. MAC significa Media Access Control, dirección de una interfaz de enlace.

Router y subinterfaz

Un router reenvía paquetes entre redes. Una subinterfaz es una división lógica de una interfaz física asociada aquí a una VLAN.

ARP

Address Resolution Protocol. Averigua la dirección MAC del siguiente salto IPv4 en el enlace local.

ICMP y ping

Internet Control Message Protocol. Ping usa mensajes de eco para comprobar alcance IP y respuesta de retorno.

CLI y configuración

Command Line Interface. Consola de comandos. Running-config es la configuración en uso y startup-config la que se conserva para reiniciar.

Regresión

Prueba de una función que ya operaba para confirmar que sigue funcionando después del ajuste.

Etapa 1 Predice antes de configurar

1. Dibuja cómo imaginas la conexión de cuatro PC con un switch y un router. ¿Qué equipo permite comunicar subredes distintas?

2. Explica con tus palabras qué indican IP, máscara, puerta de enlace y VLAN. ¿Qué pasaría con una máscara incorrecta?

3. Predice qué PC podrían comunicarse si solo creas VLAN y puertos de acceso. Conserva la respuesta para contrastarla al probar.

Regla de avance

Calcula las subredes y monta la red

Etapa 2 Distribuye 192 168 10 0 con prefijo 24

Dispones del bloque 192.168.10.0/24. Administración necesita 50 direcciones utilizables en total y Operaciones necesita 25. La cantidad incluye la puerta de enlace. Aplica VLSM, empieza por el área mayor y usa bloques consecutivos desde el inicio de la red.

1. Encuentra el menor número de bits de host que cumpla 2 elevado a h menos 2 ≥ direcciones necesarias.

2. Calcula el prefijo como 32 − h y escribe la máscara decimal. Obtén el salto de bloque en el último octeto.

3. Asigna red, primer host, último host y broadcast para cada área. Comprueba que los rangos se mantienen dentro del /24 y que no se superponen.

4. Reserva el primer host para el router y los dos siguientes para los PC del área. Intercambia el cálculo con otro equipo y justifica la capacidad.

Comprueba tus subredes

Resuelve primero en papel. Introduce tu propuesta para asignar bloques consecutivos desde 192.168.10.0/24. El primer host de cada bloque será el gateway.

Ver el procedimiento resuelto

Para 50 direcciones se necesitan 6 bits de host. 2⁶ − 2 = 62, prefijo /26 y salto 64. Administración ocupa 192.168.10.0/26, con hosts .1 a .62 y broadcast .63.

Para 25 direcciones se necesitan 5 bits. 2⁵ − 2 = 30, prefijo /27 y salto 32. Operaciones ocupa 192.168.10.64/27, con hosts .65 a .94 y broadcast .95.

Asigna ADM1 .2 y ADM2 .3 con máscara 255.255.255.192 y gateway .1. Asigna OPE1 .66 y OPE2 .67 con máscara 255.255.255.224 y gateway .65. Todas las IP comienzan por 192.168.10.

Configura VLAN y comprueba el switch

Etapa 4 Crea las VLAN y asigna los puertos

Intenta escribir la configuración desde memoria. Usa la secuencia de apoyo cuando lo necesites. Los puertos de los PC son de acceso. El enlace hacia R1 debe transportar ambas VLAN.

enable
configure terminal
hostname S1
vlan 10
name ADMINISTRACION
exit
vlan 20
name OPERACIONES
exit
interface range fastEthernet 0/1 - 2
switchport mode access
switchport access vlan 10
exit
interface range fastEthernet 0/3 - 4
switchport mode access
switchport access vlan 20
exit
interface gigabitEthernet 0/1
switchport mode trunk
switchport trunk allowed vlan 10,20
end
show vlan brief
show interfaces trunk
copy running-config startup-config

Comprueba antes de configurar R1

1. Busca Fa0/1 y Fa0/2 en VLAN 10 y Fa0/3 y Fa0/4 en VLAN 20.

2. Desde ADM1 prueba la IP de ADM2. Desde OPE1 prueba la IP de OPE2. Ambas comunicaciones deben funcionar.

3. Desde ADM1 prueba OPE1. Registra el resultado esperado en esta etapa y explica qué configuración falta.

4. Consulta show mac address-table después de generar tráfico. Relaciona una MAC con el puerto del PC y su VLAN.

Si el primer eco falla, espera que los enlaces estén activos y repite la prueba para permitir el aprendizaje ARP. El troncal puede permanecer inactivo hasta habilitar el puerto de R1.

Configura el router y verifica la red

Etapa 5 Habilita el paso entre las VLAN

Crea una subinterfaz por VLAN sobre Gi0/0. Sustituye los campos IP y MASCARA por tus cálculos. El identificador dot1Q debe coincidir con la VLAN del switch. Escribe cada comando por separado en la consola.

enable
configure terminal
hostname R1
interface gigabitEthernet 0/0
no shutdown
exit
interface gigabitEthernet 0/0.10
encapsulation dot1Q 10
ip address IP_GATEWAY_ADMIN MASCARA_ADMIN
exit
interface gigabitEthernet 0/0.20
encapsulation dot1Q 20
ip address IP_GATEWAY_OPER MASCARA_OPER
end
show ip interface brief
show ip route
copy running-config startup-config

Las dos redes quedan directamente conectadas al router. Comprueba sus entradas en show ip route y relaciona cada red con su subinterfaz.
